# shawntz/tap

The Homebrew tap for [Splay](https://shawntz.github.io/splay/), a scrolling tiling window manager for
macOS 15 or later.

```sh
brew install --cask shawntz/tap/splay
```

This installs Splay in Applications and links its `splay` command. Splay updates itself after that.

`Casks/splay.rb` is written by Splay's release script, `scripts/release.sh` in
[shawntz/splay](https://github.com/shawntz/splay), on each release. Report problems there.
